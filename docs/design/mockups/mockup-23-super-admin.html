Screen 1 — Triage Queue

Data sourceAggregate query across org exceptions (see below)
KPI rowCOUNT(orgs), SUM(mrr), COUNT(at_risk), COUNT(failed_payments)
Exception groupsCritical / High / Medium / Low — sorted by urgency_score DESC
Exc card border-left3px solid: red/orange/amber/blue by group
Actions per cardInline buttons → email, extend trial, suspend, retry payment
Badge count (sidebar)COUNT(*) WHERE resolved_at IS NULL

Screen 2 — Customer Health Board

Health scoreComputed: (login_recency×30 + load_velocity×35 + feature_depth×35) / 100
Health bar60px wide, 6px tall, color by score: ≥70 green / ≥40 amber / <40 red
Table sortDefault: health_score ASC (worst first)
Filter chipsClient-side filter on fetched data by tier / health band / trial
Row clickNavigate to /admin/orgs/[id]

Screen 3 — Org Detail

Route/admin/orgs/[id]
KPI: uninvoicedSUM(rate) WHERE org_id=? AND status='delivered' AND invoice_id IS NULL
Adoption checklist7 milestones — check org_sequences, loads, drivers, invoices tables
ImpersonatecreateAdminClient().auth.admin.generateLink({type:'magiclink', email})
Change tierPATCH carrier_details SET tier=? WHERE org_id=?
Notesadmin_notes table: org_id, body, created_by (admin profile_id), created_at

Screen 4 — Billing & Payments

Data sourceStripe webhooks → billing_events table (org_id, event_type, amount, status, card_last4, created_at)
Failed paymentbilling_events WHERE event_type='charge.failed' AND resolved_at IS NULL
RetryStripe API POST /v1/charges → charge.id
Grace periodcarrier_details.grace_period_until TIMESTAMPTZ
Expiring cardsStripe customer.sources WHERE exp_month/year ≤ now+30d

Screen 5 — Sales Pipeline

Trial orgscarrier_details WHERE tier='trial' ORDER BY trial_ends_at ASC
Days remainingDATE_DIFF(trial_ends_at, now())
Upgrade candidateStarter orgs WHERE loads_this_month ≥ 8 OR has_multiple_drivers
Extend trialPATCH carrier_details SET trial_ends_at = trial_ends_at + interval '7 days'
Offer GrowthTrigger Resend email → upgrade_offer template with promo link
