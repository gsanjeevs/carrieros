CarrierOS — Mockup 25: Maintenance (Phone-Frame, Native)

Fills a real mobile gap: maintenance/index.tsx is a fleet-wide, read-only reminders overview with no phone-frame treatment. Extends it with the per-vehicle service-log entry and document view that vehicle/[id].tsx already supports on mobile, shown here in native form for the first time.

1 — Fleet Maintenance Overview
Matches maintenance/index.tsx: overdue-first sort, org-wide for owner/dispatcher, tap-through to vehicle. Left swipe on a row reveals quick "Log Service".
