Developer Notes — Mockup 21

Desktop Shell — Shared Pattern

Fixed sidebar with role-based nav items. Same sidebar component as mockup-17 (Pro Finance Hub). Nav items rendered from a config array filtered by role: Owner sees Finance section (Fuel Log, IFTA, Settlements); Dispatcher sees Dispatch section (Queue, Messages) but NOT Finance.


Supabase RLS enforces what data each role can fetch — sidebar filtering is just UX. Desktop route: /dashboard (Owner), /dispatch (Dispatcher). Both roles: Growth tier only — redirect to upgrade page on Starter.

KPI Cards & Live Map

KPI strip: server-side aggregations via Supabase views. active_loads_count, revenue_mtd, trucks_on_road, fuel_cost_mtd, unread_messages_count. Subscribe to loads and driver_messages channels via Supabase Realtime for live badge updates.


Live map: poll truck GPS positions from ifta_state_crossings latest row per truck every 2 min (not real-time — positions are estimated, not exact). For MVP accuracy, display last known location with timestamp tooltip.

Assign Panel Logic

Driver availability: query loads for each driver's last delivery ETA. A driver is "available" if no active load with ETA after load pickup time. "Best match" tag: driver home base (from drivers.home_base) within 50 miles of pickup city.


Assign action: PATCH loads.driver_id + loads.truck_id → triggers push notification via Supabase Edge Function calling Expo Push API. Driver sees load appear in their mobile app immediately via Realtime subscription on loads table filtered by driver_id.
