Product/design review questions

  • Are loaded-mile RPM and deadhead miles enough to compare—or should we show a carrier-configured net estimate?
  • Does each board permit a unified results list and which attribution must remain visible?
  • Should “Pursue” open Contact, Offer, Bid, Tender, or Book based on provider capabilities?
  • When should an awarded result become a CarrierOS load? Prototype assumes only after confirmed booking/award.
  • How should plan entitlements and separately paid board seats be explained?
