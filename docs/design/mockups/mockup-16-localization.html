🛠 Developer Notes
Fonts
EN + ES: system font stack — no extra loading
PA: Noto Sans Gurmukhi — load conditionally
UR: Noto Nastaliq Urdu — load conditionally
RTL (Urdu only)
Set dir="rtl" on root layout div when locale === 'ur'
Flex, text-align, margins mirror automatically
Route display: explicitly reverse origin ↔ destination order in code
Arrow icon: swap → for ← in RTL mode
Language codes
'en' | 'es' | 'pa' | 'ur'
Stored in profiles.preferred_language
Cached in localStorage for offline
Translation files
messages/en.json — English (default)
messages/es.json — Spanish
messages/pa.json — Punjabi
messages/ur.json — Urdu
