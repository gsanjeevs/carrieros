Developer Notes — Mockup 18

DB Schema

Table: fuel_stops (tech-spec.md §15). Key columns: company_id, truck_id, driver_id, load_id (nullable), state (2-char), stop_date, gallons, price_per_gallon, total_cost, receipt_path, odometer.


total_cost computed client-side (gallons × price) but stored explicitly. Receipts stored in Supabase Storage fuel-receipts bucket (private, owner/driver only).

Routes & RLS

  • Driver: /my-loads/[id]/fuel
  • Owner log detail: fuel card in load detail
  • Finance: read-only (cost rollup)

Driver can INSERT for assigned load only. Owner/Solo/Dispatcher SELECT all company stops. Finance SELECT only. load_id FK enforced — can't log stop for unassigned load. Tab bar "Fuel" tab is driver-only nav.

IFTA Integration (Growth)

Fuel stop state + gallons is the "fuel purchased in state" side of IFTA formula:


(miles_in_state / total_miles × total_fuel × state_rate) − fuel_purchased_in_state × state_rate


Joins ifta_state_crossings on truck_id + state + quarter. Starter shows fuel cost only — no IFTA rollup. Growth shows full IFTA quarterly summary (see mockup-20). Form itself is ungated — all tiers can log.
