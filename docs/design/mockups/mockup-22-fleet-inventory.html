Developer Notes — Mockup 22
Truck photos: Stored in Supabase Storage truck-photos/{company_id}/{truck_id}.jpg. Fallback: type-based SVG icon (7 types from design system). Driver photos in driver-photos/{company_id}/{driver_id}.jpg.
Schema additions (trucks table): make TEXT, model TEXT, year INT, color TEXT, cab_type TEXT CHECK IN ('sleeper','day_cab','other'), vin TEXT, photo_url TEXT — all nullable.
Truck type enum: semi | box_truck | flatbed | reefer | step_deck | tanker | dump
Platform: Screens 1–2 = carrieros-web/ (Next.js desktop). Screens 3–4 = carrieros-mobile/ (Expo RN).
