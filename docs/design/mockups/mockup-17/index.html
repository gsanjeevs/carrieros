🖥 Mockup 17 — Developer Notes: Pro Desktop Finance & IFTA Hub

Layout Architecture

  • Fixed sidebar: 256px, position:fixed, full viewport height
  • Main canvas: margin-left:256px, scrollable
  • Top bar: position:sticky; top:0; z-index:20
  • Mobile (md: breakpoint): sidebar collapses to bottom nav; sidebar items become bottom tab icons
  • Grid: 4-col KPI strip → 3-col content row → 2-col analytics row

IFTA Data Source

  • State crossings auto-logged via GPS in ifta_state_crossings table
  • Fields: truck_id, driver_id, state, crossed_at, lat, lng, odometer_est
  • Quarterly summary view: ifta_quarterly_summary — miles per state per truck per quarter
  • Fuel purchases from fuel_stops table (manual Growth) or fuel card import (Pro)
  • Tax rate table: ifta_tax_rates — state, quarter, rate_per_gallon; updated quarterly
  • Net formula: (miles_in_state / total_miles × total_fuel_used × state_rate) − fuel_purchased_in_state × state_rate

Tier Gating

  • This view requires companies.tier IN ('pro','enterprise')
  • Growth can access IFTA mileage log page but not the tax computation or filing export
  • Finance desktop sidebar available from Growth+; IFTA and Fuel Analytics nav items visible but locked on Growth with upgrade prompt
  • RLS: Finance role can read all finance tables; cannot access loads with driver rate column

Fuel Analytics

  • Source: fuel_stops table — driver_id, truck_id, gallons, cost, state, odometer, logged_at
  • Cost/mile: SUM(cost) / SUM(distance_driven) per driver per period
  • Anomaly flag: fill-up > 120% of truck tank capacity, or off-route by >30mi
  • Fleet avg calculated across all active drivers for the period

Invoice Pipeline

  • Source: invoices table with status IN ('draft','sent','paid','overdue')
  • Overdue computed: due_date < NOW() AND status = 'sent'
  • Auto-reminder: scheduled job at due_date + 1 day and due_date + 7 days via Resend
  • Finance role: read/update invoices; cannot delete loads or reassign drivers

Driver Settlements

  • Source: driver_settlements table — computed on delivery, pending ACH approval
  • Settlement methods: 'percent_of_rate' | 'per_mile' | 'flat_per_load' on drivers.settlement_type
  • ACH: Stripe Connect (sub-account per driver) or manual bank transfer with status tracking
  • PDF statement: generated server-side, stored in Supabase Storage, link emailed to driver

Revenue per Mile / Lane

  • Lane = (origin_city, destination_city) normalized pair
  • Revenue/mile: load.rate / load.distance_miles
  • Margin: (rate − fuel_cost − driver_settlement − tolls) / rate
  • Negative margin: flag in UI with red color; trigger insight suggestion
